Portal Demo de Vagas ambiente de teste local — não é um portal real

Páginas de teste

Use estas páginas para testar a extensão sem tocar em portais reais:

  • Cadastro de currículo — formulário longo com dados pessoais, formação, experiências, cursos e textos livres (modelo inspirado em portais regionais).
  • Cadastro de currículo já preenchido — para testar importar do portal e comparar/mesclar.
  • Página de vaga — para testar a análise de vaga.
  • Formulário de candidatura — perguntas de triagem, pergunta aberta, dado sensível, termos, anexo e CAPTCHA.
